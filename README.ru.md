# hypr-wiggle

Любая область рабочего стола Hyprland шатается как капля воды по клику —
эффект как у *wiggle*-обоев на телефонах vivo.

Выделяешь область (например, ветки дерева на обоях), кликаешь, и она расходится
волнами и колышется как желе. Края «пришиты», поэтому эффект сливается с остальной
картинкой.

[English version](README.md)

## Как работает

- Поверх выделенной области лежит прозрачное layer-shell окно: **над обоями, но под обычными окнами**.
- По клику `grim` делает снимок области, а потом каждый кадр пиксели смещаются
  затухающей бегущей волной плюс «желейным» покачиванием (чистый NumPy, без OpenCV).
- Результат показывается через GTK4 и плавно исчезает, когда движение затухает.
- Клики складываются: каждый добавляет новую волну.

## Зависимости

Arch Linux, Hyprland, Python 3:

```sh
sudo pacman -S gtk4-layer-shell python-gobject python-numpy grim slurp
```

## Установка

```sh
git clone https://github.com/YOUR_USER/hypr-wiggle.git
cd hypr-wiggle
install -Dm755 wiggle.py ~/.local/bin/wiggle.py
```

Папка `~/.local/bin` должна быть в `PATH`.

## Использование

```sh
wiggle.py add      # выделить область мышкой (можно несколько раз)
wiggle.py list     # показать сохранённые области
wiggle.py clear    # удалить все области
wiggle.py          # запуск: левый клик по области
```

Области хранятся в `~/.config/wiggle/regions.json`.

Автозапуск в `hyprland.conf` (после запуска обоев):

```ini
exec-once = python ~/.local/bin/wiggle.py
```

## Настройка

Константы в начале `wiggle.py`: `AMP`/`SWAY` (амплитуда), `SPEED`, `WAVELEN`
(скорость и длина волны), `TAU`, `TAU2`, `DUR` (затухание и длительность),
`FREQ` (частота покачивания), `EDGE` (ширина «пришитого» края), `MAX_PIXELS`
(большие области считаются в уменьшенном размере, при лагах уменьши), `STEP`
(шаг сетки смещений).

**Совет:** выделяй только то, что должно двигаться (например, только ветки).
Нагрузка на кадр растёт с площадью.

## Ограничения

- Клик доходит только там, где область **не закрыта окнами** (эффект лежит под окнами).
- Рассчитано на **один монитор**.
- Область — снимок на момент клика, поэтому анимированные обои внутри неё замирают
  на время эффекта (плавное появление и исчезновение скрывают скачок).
- Без 3D-ускорения (например, в виртуалке) работает медленнее: бери область поменьше.
- Разработано и проверено на Arch Linux + Hyprland в виртуальной машине.

## Отладка

```sh
WIGGLE_DEBUG=1 wiggle.py                # область заливается красным
hyprctl layers | grep -B1 -A3 wiggle    # должен быть namespace: wiggle в слое bottom
```
